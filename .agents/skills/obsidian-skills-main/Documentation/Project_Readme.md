# 🚀 Project Readme

This is the primary developer readme for the Peak Excellence Next.js application, which has been configured with local database seeding and user role management.

## 🛠️ Getting Started

First, ensure you have set up your database by following the [[Database_Deployment_Guide|Database Deployment Guide]].

Once the database configuration is ready, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
