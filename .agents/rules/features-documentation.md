# System Features Documentation Rule

## AUTOMATIC FEATURE DOCUMENTATION POLICY
- Whenever a new feature, major workflow, or feature enhancement is added or modified in the project, automatically update `Document/SYSTEM_FEATURES.md`.
- Keep descriptions clear, minimal, and organized by:
  - Feature name and overview
  - Core components & workflow
  - Key modified files and APIs
  - Database schema changes (if applicable)
- Ensure the table of contents and documentation template remain accurate and up-to-date.
