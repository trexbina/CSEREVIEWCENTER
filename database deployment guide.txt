═══════════════════════════════════════════════════════════════
  CSE Review System — Database Deployment & Setup Guide
  Deploy with PostgreSQL + pgAdmin or Cloud Database
═══════════════════════════════════════════════════════════════


PREREQUISITES
─────────────────────────────────────────────────────────────
  1. Node.js (v18+)         → https://nodejs.org
  2. PostgreSQL (v14+)      → https://www.postgresql.org/download
  3. pgAdmin 4 (optional)   → Included with PostgreSQL installer on Windows
  4. Project Directory      → CSE Review System root folder


STEP 1 — Install Dependencies
─────────────────────────────────────────────────────────────
  In your terminal, run:

    npm install


STEP 2 — Create the Database
─────────────────────────────────────────────────────────────
  Option A (pgAdmin 4):
    1. Open pgAdmin 4.
    2. Expand: Servers → PostgreSQL.
    3. Right-click "Databases" → Create → Database...
    4. Database name: csereview
    5. Click "Save".

  Option B (psql command line):
    psql -U postgres -c "CREATE DATABASE csereview;"


STEP 3 — Run the Database Schema Setup (setup.sql)
─────────────────────────────────────────────────────────────
  Option A (psql command line):
    psql -U postgres -d csereview -f setup.sql

  Option B (pgAdmin Query Tool):
    1. Select the `csereview` database.
    2. Click Tools → Query Tool.
    3. Open `setup.sql` and click Execute (F5).

  This creates all tables, indexes, constraints, and default roles
  along with the initial Super Administrator account.


STEP 4 — Configure Environment Variables (.env.local)
─────────────────────────────────────────────────────────────
  Open or edit `.env.local`:

    DATABASE_URL="postgresql://postgres:YOUR_PASSWORD@localhost:5432/csereview"
    JWT_SECRET="generate-a-secure-random-32-character-secret-key"

  Replace YOUR_PASSWORD with your actual local PostgreSQL password.


STEP 5 — Default Super Administrator Login
─────────────────────────────────────────────────────────────
  URL:       http://localhost:3000
  Login ID:  admin00001  (or admin@csereview.local)
  Password:  password123
  Role:      super_admin


STEP 6 — Start the Application
─────────────────────────────────────────────────────────────
  For local development:
    npm run dev

  For Cloudflare Worker preview:
    npm run preview
